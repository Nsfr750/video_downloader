# Security Policy

## Supported Versions

Currently, only the latest version of Video Downloader is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.1.0   | :white_check_mark: |
| 1.0.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in Video Downloader, please report it to us responsibly.

### How to Report

- **Email**: info@tuxxle.org
- **Subject**: Security Vulnerability Report - Video Downloader

Please include the following information in your report:

- A description of the vulnerability
- Steps to reproduce the vulnerability
- Affected versions
- Potential impact
- If applicable, a suggested fix or mitigation

### What to Expect

- We will acknowledge receipt of your report within 48 hours
- We will provide a detailed response within 7 days
- We will work with you to understand and validate the issue
- We will coordinate the release of a fix with you

### Disclosure Policy

We follow responsible disclosure practices:

1. **Do not disclose publicly** until a fix has been released
2. We will credit you in the release notes (if you wish)
3. We will keep you informed of our progress
4. We aim to release a fix within 30 days of disclosure

## Security Best Practices

When using Video Downloader:

- Only download from trusted sources
- Keep the application updated to the latest version
- Be cautious when downloading videos from unknown websites
- Review the URLs before downloading

## Dependencies

Video Downloader uses the following main dependencies:

- **yt-dlp**: For video downloading
- **PySide6**: For the GUI
- **Wand**: For image processing

We regularly update these dependencies to include security patches.
